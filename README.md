## 🚀 Getting Started (Local Setup)

```bash
# Clone the repository
git clone https://github.com/vedashivayogi/portfolio.git

# Navigate into the project folder
cd portfolio

# Open in browser
open index.html
# or on Linux:
xdg-open index.html
# or on Windows:
start index.html
```

> No build steps required — this is a static HTML/CSS/JS portfolio.
